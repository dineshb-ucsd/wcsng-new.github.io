⚡ This is the most important component in the entire system

The backscatter modulator is a single NMOS transistor (maybe W=50 µm, L=minimum) connected across the tag's antenna pads (RF+ to RF−). That's it. One transistor. Its gate is driven by the FM0 encoder output. When the gate goes high, the MOSFET turns on and effectively short-circuits the antenna terminals. When the gate goes low, the antenna sees the chip's normal input impedance.

The reader's CW signal bounces off the antenna. The reflection coefficient changes depending on whether the MOSFET is on or off. The reader sees this changing reflection as a modulated signal — and the pattern of ON/OFF switching, set by the FM0 encoder, carries the tag's EPC data.

The tag NEVER generates or transmits any RF signal. It only reflects the reader's own signal with two different impedances. The data rides on the difference between these two reflections.

MOSFET ON state (gate high)

  • Drain-source resistance: ~5–10 Ω (essentially a short)
  • Antenna impedance seen: Z₂ ≈ 0 + j0 Ω (short circuit)
  • Reflection coefficient: Γ₂ ≈ −1 (total reflection, phase-inverted)
  • All incoming power is reflected back — maximum reflected amplitude
  • The reflected wave is 180° phase-shifted from the incident wave

MOSFET OFF state (gate low)

  • Drain-source resistance: > 1 MΩ (open circuit)
  • Antenna impedance seen: Z₁ = chip's input impedance (charge pump + shunt)
  • For Monza R6: Z₁ ≈ 1.56 kΩ ∥ 1.25 pF (complex impedance)
  • Reflection coefficient: Γ₁ — partial reflection, different phase than Γ₂
  • Some power is absorbed (harvested), the rest reflected at a different phase/amplitude

What the reader sees

The reflected signal toggles between Γ₁ and Γ₂ at the FM0 data rate (40–640 kHz). The reader's IQ mixer sees this as a baseband square wave:

  • Modulated return = ΔΓ = Γ₂ − Γ₁ — this carries the data
  • Structural return = (Γ₁ + Γ₂)/2 — the DC component, carries phase info
  • The modulated return is what the bit detector locks onto
  • The structural return's phase is what phase-based RFID sensing measures — anything that changes the tag's load impedance shifts it

Sensing through Γ₁

When a sensor whose impedance depends on the quantity being measured (for example a capacitive or resistive sensor) loads the tag's antenna port, it changes Z₁ — the "OFF" impedance.

  • Stimulus changes → sensor impedance changes → Z₁ changes → Γ₁ changes → phase of the structural return shifts
  • The Γ₂ state (short) is largely unaffected — the MOSFET dominates when ON
  • A second, identical tag IC without the sensor serves as a reference, so the differential phase Δφ isolates the sensor signal

Modulation depth and link budget

  • Modulation efficiency: |ΔΓ|²/4 determines how much of the incident power becomes modulated backscatter. Typical: −10 to −20 dB relative to incident power.
  • Radar cross section: The tag's effective antenna area for backscatter, σ = G²λ²|ΔΓ|²/(4π). Typical: ~0.01 m² for a UHF tag.
  • Round-trip loss: Reader → tag → reader follows 1/d⁴ (fourth power!) because the signal traverses the path twice. This is why RFID range is limited to a few meters.
  • Switching speed requirement: BLF up to 640 kHz — trivially fast for even the smallest MOSFET. The transistor's fT is in the GHz range.

Signal flow

Input (gate): FM0-encoded digital signal from the line encoder. A square wave at the BLF rate, encoding EPC bits.

Input (drain/source): 915 MHz CW from the reader, arriving via the tag antenna. Amplitude: ±200 mV at the chip pads (at threshold distance).

Output: The reflected wave leaving the tag antenna back toward the reader. Its amplitude and phase toggle between two states (Γ₁ and Γ₂) at the FM0 rate. The reader's IQ mixer extracts this modulation as a baseband signal. The EPC is encoded in the switching pattern; the phase reflects the tag's load impedance, which is what RFID sensors exploit.

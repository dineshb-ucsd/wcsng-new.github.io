What it is physically

Synthesized digital logic — a finite state machine implementing the full EPC Gen2 (ISO 18000-63) air interface protocol. About 5,000–15,000 logic gates total, running off the ring oscillator clock at ~1.5 MHz. Includes a CRC-16 generator/checker and a command decoder.

What it does

Parses incoming commands from the envelope detector, manages the tag's state transitions, reads the EPC from memory, and orchestrates the backscatter response. The typical inventory round: Query → pick slot → wait → send RN16 → receive ACK → send EPC+CRC.

Why it matters

  • Implements anti-collision: multiple tags in the field take turns talking (slotted ALOHA)
  • CRC-16 on every packet ensures data integrity
  • Must handle power loss gracefully — if VDD drops mid-transaction, it resets cleanly
  • Access control: kill password, access password for locking memory regions

Signal at this point

Input: Decoded command bits from envelope detector.

Output: Response bits (preamble + EPC + CRC-16) sent to the FM0 line encoder.
